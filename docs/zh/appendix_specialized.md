# 附录：特化路径参考

**强烈推荐：在 tune 或测性能之前，先用
`python -m pyqcd.einsum.verify_specialized "<equation>"` 查一下这条方程。**
它在毫秒级回答“这条方程到底有没有特化路线”，不构造操作数、不调用 `contract()`，
因此可以直接放进生产代码的启动自检。

当前语料覆盖：

* pyqcd 版本：`0.5.4`
* 特化路径：**8638** 条（基础表 2582 + 附录变体 6056）
* 不同拓扑签名：**8638** 个，分 **24** 个桶

匹配依据是**拓扑签名**，不是字符串：字母叫什么无关紧要（`ij,jk->ik` 与 `ij,jb->ib`
走同一条路径），空白与省略输出不改变签名，而操作数顺序与操作数内指标顺序会改变签名。

## 1. 查询单条方程

退出码让查询可直接用于脚本：`0` 命中特化路径、`1` 未命中（走通用分步路径）、
`2` 方程非法或参数写错。

```bash
python -m pyqcd.einsum.verify_specialized "agbh,cmdn,eqfr,ospt,ikjl,ce,mo,gi,kq,bdf,np,hj,lrt->as"
python -m pyqcd.einsum.verify_specialized "<eq>" --json
```

文本报告逐字段回答：

| 字段 | 含义 |
|---|---|
| `拓扑签名` | 重编号后的签名：指标按全式首次出现顺序换成序号 |
| `元数/槽位` | 操作数个数与指标槽总数（操作数加输出） |
| `摘要` | 签名的稳定哈希；路径名为 `topology:<摘要前 8 位>` |
| `特化开关` | 当前是否启用特化（`PYQCD_EINSUM_SPECIALIZE`） |
| `结果` | `HIT` 并给出命中的路径，或 `MISS` 并给出原因 |
| `声明内核` | 命中**声明**可用的内核——不代表实际一定会下发 |
| `语料出处` | 来源：`seq`、任务号与该方程出自哪个语料情形 |
| `代表写法` | 产生该条目的语料方程原文 |
| `操作数角色` | 每个操作数在语料中的角色（perambulator、gamma、VDV/VVV） |

未命中时报告会说明原因：该方程不在 `wick_12cases` 语料内、没有形状特化路径，且不存在
能命中已知形态的等价写法。加 `--equivalence true` 时，未命中报告还会列出等价写法以及
配套的输入侧张量调整与输出侧结果映射（若有）。

`声明内核` 只是**声明**：实际下发还取决于 `out=`、dtype 与当前数组后端对应的原生库
是否可用。要连数值一起验，用测试侧入口（不在 `pip install` 的发行物里）：

```bash
python -m pyqcd.testing.einsum.verify_specialized "<eq>"
```

## 2. 怎么判断走了哪条路

两种提示都是**每形态每进程一次**，且跟随 locale（`zh_*` 说中文，其余说英文；可用
`PYQCD_EINSUM_LANG=zh|en` 强制指定）。

| 情形 | 日志 |
|---|---|
| 语料路径，原生内核跑成 | `[pyqcd.einsum] 专用路径: topology:<摘要> [match: topology] [kernel: kupl_topology] ...` |
| 语料路径，内核不可用 | `[pyqcd.einsum] 专用路径: topology:<摘要> [match: topology] [plan-cache] ...` |
| 语料之外 | `[pyqcd.einsum] 通用路径: 未命中特化形态 (...)` |

`[match: …]` 说明命中的是哪个形态族，`[kernel: …]` 说明真正执行的是哪条路线，
`[plan-cache]` 表示只复用了计划。它是否比通用路径更快取决于形状、dtype 与设备——请用
`--tune` 实测。用 `PYQCD_EINSUM_NOTICE=0` 关闭全部提示；用
`PYQCD_EINSUM_SPECIALIZE_VERBOSE=1` 让特化提示**每次命中**都打印。

## 5. 重新生成逐条清单

逐条清单（全部 8638 条方程及其稳定 `seq` 序号）由 `wick_12cases` 语料自动生成、从不
手写，因此它留在仓库里而不是这一页上。用测试侧生成器重新生成：

```bash
python -m pyqcd.testing._gen_specialized_appendix
```

早期版本还额外登记了 5 条字面表（`gauge-propagator(E4)`、`gamma-sandwich(E5)`、
`sush-2pt(S1)`、`sush-3pt-munu(S2)`、`sush-2pt-mu(S3)`）。它们是退役专用内核的遗留项，
从来不属于本语料，现已删除：上面列出的全部由当前拓扑特化内核服务。
