# 格点 QCD 收缩的 CUDA 特化

从用户给定的算符或正在运行的参考实现出发。分析请求交付物理等式、候选路径、开销和验证办法。实现请求再将选中的路径编译为原生程序，接入调用方并实测。需要解析 lqcddb API 时查看所选源码和 `$lqcddb`。需要另写整套组态读取、MPI 和保存程序时可配合 `$contraction-creator`。

## 还原实际计算

1. 锁定参考文件、版本及实际调用入口。动态生成的方程从运行时 Wick plan 提取，列出图标识、系数 $c_d$ 和实际输出排列，写成 $C=\sum_d c_d T_d$。核实参考接口返回的是裸图 $T_d$、带系数图 $c_d T_d$ 还是总和。基准文件可能只计时其中一条方程。
2. 为每个操作数列出物理角色、味、时间方向、轴序、各轴长度、共轭或转置、输入精度。区分源模、汇模和各流的模数。给输出轴标出自由、配对或求和的含义，例如同一个保留的 $\mu$ 产生对角通道 $C_{\mu\mu}$，独立的 $\mu,\nu$ 产生两个轴。记录动量顺序和单位。
3. 确认与本算符有关的 gamma 次序、Wick 符号、相位、边界和源平均定义。若采用随机蒸馏，标明哪些因子共用抽样，原参考如何加权。用能区分候选解释的一组小张量或一个真实时间点核对。若仍有影响物理量定义的歧义，指出需要确认的约定，同时推进已有条件下的形状分析。
4. 记录生产尺寸、输入/计算/累加/输出精度、设备、峰值可用显存和基线计时边界。明确用户需要的产物是单图、逐图输出、带符号总和还是特定投影。目标可能是单次延迟，也可能是不断换数据时的吞吐。

## 从物理等式产生收缩路径

- 对可利用的投影、稀疏 gamma、对称性或味简并，先用实际基底写出等式、作用的端点和归一化。在小尺寸比较“原式算完再变换”和“将变换吸收到相邻张量”。单侧投影、双侧投影和最终迹有各自的输出。将已证明的降维写进各图形状后重新搜路径。
- 对每张图尝试沿传播线先合并固定 gamma、顶角或顺序传播子，再闭合环或重子块。用形状上的 greedy 或子集动态规划和现有参考路径比较。两个因子共享的指标若仍出现在剩余因子或最终输出，继续保留它。独立分支可以分别归约，再取外积或乘回标量。
- 把多图候选树并成有向无环图。以输入身份、两端口的配对、方向、共轭、投影和输出轴序识别可共享的节点。对每个节点注明依赖哪些时间、动量和流分量，按实际调用次数计成本。单图最省乘加的路径，合并后仍可能重复整块计算。
- 比较复乘加数、重排读写字节和同时存活的缓冲区。可用随附的形状工具查看一条方程的候选步骤，再对整组图计算共享与批次开销。给出首选路径、限制资源和能证伪该选择的计时对照。[形状分析与 CUDA 实现方法](references/cuda-implementation.md)

## 编写 CUDA 和连续输入接口

固定算符拓扑，把张量重排、GEMM、投影、归约及输出符号编码为可复用的执行计划。先跑通与参考同定义的简单实现，再根据计时选择热点内核。明确哪些输入留在 GPU、哪些可广播、每张卡在哪个流上执行以及同步点。多个时间片连续输入时，计划缓存形状、调度和工作区，每次调用重新绑定操作数。若缓存数值中间量，需要输入不可变或可验证的版本信息。

若路径用到了某个 gamma 的数值、稀疏支撑或投影关系，把它写成接口中的固定约定。若允许调用方替换该矩阵，用足以区分特化条件的标识或数值检查选择计划，并用同形状、不同支撑或系数的输入验证重建或回退路径。

生产 Python 入口可采用 `contract(*tensors)`。写明每个位置参数、来源、轴序、dtype、输出排列、Wick 系数是否已乘、缓冲区何时可以覆盖。公开同步返回，或在异步入口返回可等待的事件并约定输入/输出寿命。矩阵布局、工作区估计、热点选择与测量口径见 [CUDA 实现方法](references/cuda-implementation.md)。

## 判断计算正确且确实加速

1. 小尺寸用独立的显式 einsum 或直接求和。不同端使用可区分的长度或标记，用非对称复数暴露错轴、误共轭和错号。每张图和带符号总和分别对照。涉及物理约束时，再构造满足约束的顶角、传播子或权重验证相应恒等式。
2. 对照用户指定的动态库或既有结果，核实导入位置和当前数据注册。用相同物理约定比较全部相关分量、动量、图系数和归一化。在资料可用且任务包含生产验证时，从原始数据核对一个有代表性的组态切片。如含不等价的时间分支，分别验证。
3. 对每种请求的输入精度，区分“同一舍入输入提升到高精度”的实现误差和“与原始高精度数据相比”的输入误差。记录最大绝对差、逐图最坏相对 $L_2$、总和相对 $L_2$。参考范数为零时用绝对误差。强相消时同时给出 $\sum_d |c_d|\|T_d\|_2/\|\sum_d c_d T_d\|_2$。若误差产生在逐图收缩阶段，用更高精度重算相关中间量，再做带符号求和。
4. 用不同数据覆盖原地址、再换一组地址。有分批或分卡时覆盖尾批和拼接顺序。计时用同卡同数据和相同输出，分别报告首次规划、预热后的同步收缩和生产端到端时间。列明测量规模、重复次数和未实测的设备或分支。

需要对照已交付的特化程序时，查看 [E32P29 四点实例](references/e32p29-example.md)。其中的投影、模数、图数、权重和实测速度都属于该算符及数据。
