                     Wick 图、蒸馏顶点和统计观测量直接映射为 Python 张量对象。

Wick 自动生成：从算符 DSL 到带符号 einsum

   Table. Pseudocode for wick_contraction
   Input: Osink , Osrc , J, Cpt ∈ {bubble, 2pt, 3pt, 4pt}, optional prefixes
   if Cpt = 2pt then J ← [ ]
   normalize: ensure each operator begins/ends with |；extract global numeric coeﬀicient
   expand wildcard: q → {u, d, s, c, b, t}, l → {u, d}，take Cartesian products
   for each flavor substitution do:
      count Nfq , Nfq̄ ; if Nfq 6= Nfq̄ then skip this substitution
      group by flavor; enumerate every permutation of the anti-quark list
      form all cross-flavor products of one-to-one pairings
      assign index pairs ab, cd, ef, . . . to every quark/anti-quark field
      compute Ninv from field positions; set sign = (−1)Ninv × coeﬀicient
      label intervals as tsink, tsrc, tcur0, . . . according to | boundaries
      insert gamma indices, create VDV for two fields and VVV for three fields
      build peram, γ, V inputs and lhs → free indices
   end for
   Output: {peram, γ_pos, V, result_sign, result_indx, result_name}

 来源：直接实现：contraction/autowick.py:6--63,156--224,235--449；费米符号是场位置逆序数，不是事后拟合参数。
