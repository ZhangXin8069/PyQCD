# 自动任务报告: c32p29 P4 的 bootstrap seed 敏感性

## 工作结果

**要求:** 检验只改变随机数种子能否稳定地减轻 `tsep=10` 的 ratio 误差突增. 本次未剔除任何 bootstrap replica, 也未使用 `|R|` 阈值截尾.

1. 按现有定义重算了逐组态 `C3disc`, 对 seed `0, 1, 42, 12345` 各生成 3000 个 bootstrap replica, 再逐 replica 计算 `R=Re(C3disc(z=1)/C3disc(z=0))`. 使用 `c32p29`, 984 个组态, 排除 `[18350, 23050, 28400]`, 三个空间方向 `x,y,z`; 比较 `tsep=10` 的 `tau=0,1,2,8,9,10` (图中 `x=tau-5`). 配置见 `/public/home/huangcl/07_pion_gluon_pdf/autotask11/05_self_ratio/_1.log`, 第 1-6 行; seed 完成情况及总耗时见第 51-59 行.

2. **先验证 seed=0 复算没有改变原计算定义:** 它与正式 `ratio.npy` 在选定六个 `tau` 的 18000 个 replica 点上, 最大绝对差为 `4.17e-11`. 数据见 `/public/home/huangcl/07_pion_gluon_pdf/autotask11/05_self_ratio/01_test/c32p29/P4/seed0_formal_ratio_check.csv`, 第 2 行; 逐组态 bootstrap 和 `C3disc`/ratio 公式见 `05_self_ratio/1_compare_bootstrap_seeds.py`, 第 168-188 行.

3. **更换 seed 没有稳定地消除突增, 反而显示误差估计受稀有极端 ratio 强烈控制:**
   - `tau=0`: 四个 seed 的标准差从 `2.306` 到 `54.690`; seed=1 抽到 `|R|=2996.46`, 此 replica 的 `|C3disc(z=0)|` 只有该坐标中位数的 `2.02e-5`.
   - `tau=1`: 标准差范围 `0.382-2.311`; `|R|` 最大值在四个 seed 中分别为 `123.83, 42.20, 11.99, 16.17`. 因此换 seed 可以改变最大极端值, 但并没有可靠地消除尾部.
   - 右端 `tau=9,10`: 标准差分别在 `0.602-2.751` 和 `2.073-14.064` 间变化; 四个 seed 的 `|R|>2` 数量分别为 `tau=9: 24-43`, `tau=10: 72-96`. 这不是同一个固定 bootstrap 编号造成的, 而是不同 seed 都能抽到小分母对应的长尾值.
   - 对照点 `tau=2,8` 稳定得多: 标准差分别为 `0.0162-0.0169` 和 `0.0220-0.0291`, 四个 seed 均没有 `|R|>2`.

   这不是中心分布整体平移或变宽同等幅度: 例如 `tau=1` 的 16%-84% 分位区间在不同 seed 下都约为 `[0.927,1.002]`, 但标准差仍从 `0.382` 变到 `2.311`; 变化主要来自极少数长尾点, 而非典型 replica 整体偏离.

   上述数字可按 seed/tau 直接在 `/public/home/huangcl/07_pion_gluon_pdf/autotask11/05_self_ratio/01_test/c32p29/P4/tsep10_seed_summary.csv` 复核: seed=0 为第 2-7 行, seed=1 为第 8-13 行, seed=42 为第 14-19 行, seed=12345 为第 20-25 行. 表中同时给出均值、中位数、16/84 分位数、最大 `|R|`、`|R|>2` 数目及最大 `|R|` 所对应的分母相对中位数.

**结论:** 随机数种子只能改变这 3000 次 bootstrap 是否抽到特别小的分母, 不能修复该 ratio 的尾部分布. 某个 seed 可能偶然显得平滑, 但这组独立 seed 的比较显示它不稳定; 特别是 `tau=0,1,9,10` 的离群数和标准差均随 seed 显著变动, 同时极端 ratio 与远小于典型值的 `C3disc(z=0)` 分母相伴. 因此不能挑一个“好看”的 seed 当作误差修正, 也没有把全部 `|R|>2` 删除. 中位数及 16/84 分位数比标准差稳定得多, 表明中心部分较集中而长尾主导标准差; 但这不等于可以把正式误差改成分位数误差.

正式 `ratio.npy` 未作修改.

## Q&A

Q1: 为避免只挑到一个偶然较好的 seed, 如何设置比较范围?

A1: 将已用的 seed=0 作为复现基准, 另外预先固定 seed=1、42、12345; 每个 seed 保持 3000 个 replica、相同配置筛选和相同物理定义.

依据: `_1.log` 第 4-5 行记录样本数及 seed 列表.

影响: 可以区分“某次抽样偶然没抽到极端值”和“换 seed 后估计稳定”; 没有按误差大小筛 seed.

Q2: 单张完整尺度图会不会让正常点难以比较?

A2: 同时交付完整尺度图和标明截断范围的局部图; 局部图只辅助读中心区域, 不能用来判断完整误差大小.

依据: 两张图的输出路径如工作结果第 4 点; 局部图题注明 `error bars clipped`.

影响: 既保留极端误差的真实幅度, 也能直接比较邻近 `tau` 的中心趋势.
