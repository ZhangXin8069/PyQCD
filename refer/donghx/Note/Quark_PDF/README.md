# Quark PDF note

`quark_pdf_note.tex` is an English note on unpolarized, helicity, and
transversity quark PDFs and the current connected lattice calculation.
References are stored in `reference.bib`.

The note distinguishes tested bare coordinate-space matrix elements from
renormalized and LaMET-matched physical PDFs.  Transversity is explicitly
marked as pending external sign-convention validation.

Build with Tectonic:

```bash
tectonic quark_pdf_note.tex
```
