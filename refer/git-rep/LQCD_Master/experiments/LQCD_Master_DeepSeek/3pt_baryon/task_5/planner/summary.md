## Physics Objective

Compute the three-point correlation function for the flavour-changing transition $\Lambda \to p$ mediated by the vector current $J_x = \bar{u}\gamma_x s$:

$$C_3(\tau) = \sum_{\vec{z}} \mathrm{Tr}_{\mathrm{spin,color}}\bigl[ G_l^{\mathrm{seq}}(\vec{z},\tau;0)\; \gamma_x\; S_s(\vec{z},\tau;0) \bigr], \qquad \tau = 0,\dots,8,$$

where $G_l^{\mathrm{seq}}$ is the light-quark sequential propagator (two-dagger convention) and $S_s$ is the forward strange-quark propagator, both originating from a point source at $(0,0,0,0)$.  The positive-parity projector $T = (1+\gamma_t)/2$ isolates the ground-state baryon channel.

---

## Strategy

### Hadron operators

| Role   | Hadron      | Interpolating operator                          | Flavour |
|--------|-------------|-------------------------------------------------|---------|
| Source | $\Lambda$   | $\epsilon^{abc}(u^{aT}C\gamma_5 d^b)s^c$       | $uds$   |
| Sink   | $p$         | $\epsilon^{abc}(u^{aT}C\gamma_5 d^b)u^c$       | $uud$   |

### Propagators (three inversions per configuration)

1. **Forward light** $S_l(x;0)$ — point source at $(0,0,0,0)$, stout-smeared gauge links (1 step, $\rho=0.125$, ndim=4).
2. **Forward strange** $S_s(x;0)$ — same source, same smeared links.
3. **Sequential light** $G_l^{\mathrm{seq}}$ — built via the two-dagger convention:

   - **B-block construction** (at $t_f=8$): the forward light propagator evaluated at all spatial sites is contracted with the proton sink operator and projector $T$.  This yields the sequential-source block $B^{rf}_{\rho\lambda}(0)$ with **two topologically distinct terms** — a direct term and an exchange term — carrying a **relative minus sign** that originates from fermion antisymmetry in the Wick contraction:

     $$B^{rf}_{\rho\lambda}(0) = \sum_{\vec{x}} \epsilon^{abc}\epsilon^{def} (C\gamma_5)_{\alpha\beta}(\gamma_5 C)_{\beta_1\alpha_1} T_{\lambda\gamma}
       \bigl[ S_l^{ad}_{\alpha\alpha_1}(x,0) S_l^{be}_{\beta\beta_1}(x,0) \delta^{cr}\delta_{\gamma\rho}
           - S_l^{ar}_{\alpha\rho}(x,0) S_l^{be}_{\beta\beta_1}(x,0) S_l^{cd}_{\gamma\alpha_1}(x,0) \bigr]$$

     The einsum for this step is generated by a dedicated tool call (`generate_einsum(type="sequential_source_block", ...)`) that produces both terms with the correct sign.

   - **First dagger**: $\eta^{\mathrm{seq}}(0) = \gamma_5 B^\dagger(0) \gamma_5$.
   - **Solve**: $D_l G^{\mathrm{seq}} = \eta^{\mathrm{seq}}$ with the same light-quark Dirac operator.
   - **Second dagger**: $G_l^{\mathrm{seq\_dag}} = \gamma_5 G^{\mathrm{seq}\dagger} \gamma_5$ (the code variable used in the final trace).

### Contraction

$S_l(x;0)$ is **not** directly contracted in the final $C_3$ — it serves exclusively as input to the B-block construction.  The final trace uses only $G_l^{\mathrm{seq}}$ and $S_s$, with the einsum generated by `generate_einsum(type="baryon_3pt", source="Lambda", sink="proton", current=("s","u","gamma_x"))`.

## Key revisions from the critique

1. **Explicit B-block construction**: The sequential-source block $B$ is now fully specified with both the direct and exchange terms, the relative minus sign, and the index structure.  A dedicated tool call (`type="sequential_source_block"`) is referenced for generating the einsum, separate from the final-contraction tool call.

2. **Two-term sign**: The plan explicitly states that the minus sign between the direct and exchange terms is essential and originates from fermion antisymmetry.  Using only one term would produce a physically incorrect sequential source.

3. **Clarified propagator roles**: The measurement section now distinguishes `sequential_source_input: prop_l_fwd` (used only in the B-block) from `forward_propagator: prop_s_fwd` (used in the final trace) and `sequential_propagator: prop_l_seq`.  The description makes clear that `prop_l_fwd` is not directly contracted in $C_3$.

4. **Contact-term warning**: An explicit note flags that $\tau=0$ and $\tau=t_f=8$ carry current-at-source/sink contact terms and overlap artifacts; these points are included in the raw output but should be excluded from subsequent physical fits.

5. **Excited-state contamination note**: The `extras` list notes that a bare point source at $t_f=8$ ($\approx 0.84$ fm) without Gaussian/Wuppertal smearing risks significant excited-state contamination in a baryon three-point function.

## Requirement satisfaction

- **Only 3pt, no 2pt** — the plan includes exclusively the three-point correlator; no two-point contractions are scheduled.
- **Vector current $\gamma_x$** — the current insertion is `gamma_x` (spatial direction 1 in the DeGrand-Rossi basis).
- **Point source, zero momentum** — both forward propagators originate from a single spacetime point with no momentum projection.
- **Stout smearing** — applied to gauge links before every inversion (forward and sequential) with the specified parameters.
- **Sequential source at $t_{\mathrm{seq}}=8$** — the sink is fixed at timeslice 8 and the sequential source is constructed at the origin following the full two-dagger convention with both direct and exchange terms.
- **Raw text output** — the result file contains only space-separated numbers with no header.
