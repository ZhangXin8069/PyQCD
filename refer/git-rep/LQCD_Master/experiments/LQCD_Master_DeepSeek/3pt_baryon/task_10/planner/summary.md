## Physics Objective

Compute the three-point correlation function for the semileptonic decay $\Lambda_b \to p$ mediated by the $b \to u$ vector current $\bar{u}\gamma_1 b$, using the sequential-source method. This is a prototype calculation for heavy-to-light baryon transition matrix elements.

## Key Revisions (from peer review)

1. **Sequential-source placement (critical fix)**. The sequential source is a **volume source spanning the entire spatial lattice at $t_f=8$**, not a point source at $[0,0,0,0]$. For zero sink momentum, the proton sink block $B$ sums over all spatial points at $t_f$, so the sequential source $\eta^{\text{seq}} = \gamma_5 B^\dagger \gamma_5$ lives on the full time slice. The plan now specifies `source_timeslice: 8, spatial_extent: volume`.

2. **Contraction notation (critical fix)**. The correlator is $C_3(\tau) = \sum_{\vec{z}} \operatorname{Tr}[ G_l^{\text{seq}}(\vec{z},\tau) \; \gamma_1 \; S_b(\vec{z},\tau; 0) ]$, where $G_l^{\text{seq}}$ originates from the **sequential source at $t_f=8$** (not the origin) and $S_b$ is the forward bottom propagator from the **point source at $t=0$**. The previous plan's notation `G_l_seq(z,τ; 0,0)` was physically wrong.

3. **Bottom-quark solver algorithm (fix)**. The plan now explicitly specifies `algorithm: cg` for the bottom propagator, removing the ambiguity where the executor might default to multigrid (which fails for heavy quarks).

4. **Contraction code generation (fix)**. The contraction is routed through `generate_einsum(type='baryon_3pt', source_hadron='Lambda_b', sink_hadron='proton', current='ub_Vx', …)` rather than relying on a hand-coded trace formula. This ensures correct spin-color einsum including color-epsilon tensors, $C\gamma_5$ structures, both Wick topologies, and the parity projector.

5. **Bottom quark mass caveat (documented)**. The mass $m_b = 1.5$ (lattice units) is substantially lighter than the physical $b$-quark mass. The result corresponds to a bottom-like heavy baryon, not a physical $\Lambda_b$. This is noted in `extras`.

## Strategy

**Sequential-source method** — standard for baryon three-point functions:

1. **Forward light propagator** $S_l(x;0)$: point source at $[0,0,0,0]$, multigrid-preconditioned CG on stout-smeared links.
2. **Forward bottom propagator** $S_b(x;0)$: same point source, plain CG (no multigrid) on stout-smeared links.
3. **Sequential light propagator** $G_l^{\text{seq}}$: the proton sink block $B$ is constructed at $t_f=8$ from the forward light propagator, $\varepsilon$ tensors, $C\gamma_5$ structures, and the parity projector $T=(1+\gamma_4)/2$. The sequential source $\eta^{\text{seq}} = \gamma_5 B^\dagger \gamma_5$ is placed across the entire spatial volume of time slice 8 (two-dagger convention), then inverted with multigrid-preconditioned CG.
4. **Contraction**: $C_3(\tau) = \sum_{\vec{z}} \operatorname{Tr}[ G_l^{\text{seq}}(\vec{z},\tau) \, \gamma_1 \, S_b(\vec{z},\tau; 0) ]$ for $\tau = 1,\dots,7$, generated by `generate_einsum`.
