## Physics Objective

Compute the zero-momentum two-point correlation function of the **Ξ⁻ baryon** (quark content **dss**) on a single gauge configuration (cfg 10000) of the C24P29 ensemble.  The target is the positive-parity ground-state correlator $C(t) = \operatorname{Tr}[P^+ \langle \mathcal{O}_{\Xi}(t) \bar{\mathcal{O}}_{\Xi}(0) \rangle]$ with $P^+ = (1+\gamma_4)/2$.

## Strategy

- **Interpolating operator**: $\mathcal{O}_{\Xi} = \epsilon^{abc} (s^{Ta} C\gamma_5 d^b) s^c$ with the Cγ₅ diquark as specified.
- **Parity projector**: $T = (1+\gamma_4)/2$ (positive-parity channel).
- **Source**: Single point source at spacetime origin [0,0,0,0], zero momentum.
- **Gauge links**: Stout-smeared before every inversion (ρ = 0.125, 1 step, 4-dim).
- **Propagators**: One light (d, κ = −0.277, `prop_l`) and one strange (s, κ = −0.2400, `prop_s`) from the same source, both with point sink.  The two strange quark lines reuse `prop_s`.
- **Strange mass – unitary choice**: The strange solver uses κ_s = −0.2400, matching the sea strange mass encoded in the configuration path (`ms-0.2400`).  This ensures the calculation is unitary (valence = sea).  The ensemble `quark_mass.strange` entry (−0.2356) is a partially quenched physics kappa; the unitary κ is preferred for spectroscopy.
- **Quark-line mapping** (explicit): quark **a** (diquark s) → `prop_s`, quark **b** (diquark d) → `prop_l`, quark **c** (spectator s) → `prop_s`.
- **Wick contraction**: Two topologies (direct and exchange).  After epsilon-tensor index relabeling, both contribute with the same sign — the pattern is identical to the proton case with two identical light quarks.  The contraction must be generated by `generate_einsum(type="baryon_2pt")`; any hand-derived formula in documentation is for illustration only.
- **Output**: Plain text file (no header, no metadata), one correlator value per time slice.

## Issues Addressed from Peer Review

1.  **Strange mass**: prop_s solver κ changed from −0.2356 → **−0.2400** to achieve a unitary valence = sea calculation.  The cfg_path `ms-0.2400` identifies the sea strange mass; using it avoids a ~1.8% partial-quenching mismatch.
2.  **Multigrid blocking**: The default two-level blocking [[6,6,6,3],[4,4,4,6]] yields only 1 site/rank on the coarsest level with process grid [1,1,1,4] (local 24³×18), which can silently degrade the MG solve.  The solver notes now prescribe a safe alternative: single-level [[4,4,4,3]] or two-level [[4,4,4,3],[2,2,2,3]], giving O(10²) sites/rank on the coarsest level.
3.  **Contraction formula**: The hand-derived exchange-term expression has been removed from the summary to avoid ambiguity.  The plan delegates all contraction work to `generate_einsum`.
4.  **Quark-line mapping**: The flavor-to-propagator assignment is now explicit: quark lines a and c → `prop_s`, line b → `prop_l`.

## Known Limitations

- **Single configuration, point source**: Statistics are limited to one gauge configuration with a single unsmeared point source.  For production baryon spectroscopy the reference recommends smeared sources and multiple configurations; the current setup is suitable for a quick first look or debugging.  The resulting correlator may carry large statistical noise.
- **Single sink type**: Point sink only (SP correlator); no SS/SP matrix for variational analysis.
