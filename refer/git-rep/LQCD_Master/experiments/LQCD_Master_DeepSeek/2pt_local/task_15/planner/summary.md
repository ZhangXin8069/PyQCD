## Physics Objective

Compute the zero-momentum two-point correlation function of the **Xi_c+ (usc)** charmed baryon on the C24P29 ensemble (24³×72, a≈0.105 fm, Nf=2+1+1 Wilson-clover, cfg 10000).  The correlator will be used to extract the ground-state mass of the J^P = 1/2^+ Xi_c+.

## Interpolating Operator

The Xi_c+ is built with a spin-0 us diquark and a charm spectator quark:

```
O_{Xi_c+} = ε^{abc} (u^{Ta} Cγ5 s^b) c^c
```

The Cγ5 diquark selects the most attractive scalar channel for the positive-parity ground state.  A positive-parity projector P^+ = (1+γ_t)/2 is applied to isolate the forward-propagating 1/2^+ state.

## Propagators

Three distinct quark propagators from a single **point source at [0,0,0,0]**:

| Propagator | Flavor | κ (mass)  | Solver                     |
|------------|--------|-----------|----------------------------|
| prop_l     | light  | -0.277    | Multigrid [6,6,6,3]/[4,4,4,6] |
| prop_s     | strange| -0.2356   | Multigrid [6,6,6,3]/[4,4,4,6] |
| prop_c     | charm  | +0.4159   | Multigrid (primary), CG fallback |

All inversions use stout-smeared gauge links (n_steps=1, ρ=0.125, ndim=4) and clover coefficient c_sw = 1.160920226.

## Wick Contraction

Because all three quark flavors (u, s, c) are distinct, there is **only one Wick contraction topology** — no exchange term arises.  The contraction code is generated by the `generate_einsum` tool with `type=baryon_2pt`.

## Risks and Mitigations (from peer review)

### 1. Charm-quark solver convergence
The multigrid levels `[6,6,6,3]/[4,4,4,6]` are optimised for light quarks and may stall or fail for the heavy charm quark (mass 0.4159).  **Mitigation**: if multigrid does not converge within maxiter=20000 at tolerance 1e-12, fall back to a standard CG solver with the same tolerance and maxiter.  The ensemble providers should confirm whether these multigrid levels have been validated for charm.

### 2. Point-source ground-state overlap
A point source without Gaussian/Wuppertal smearing gives poor ground-state overlap for baryons, leading to significant excited-state contamination.  **Mitigation**: the current point-source setup is flagged as a **validation run only**.  For production-quality Xi_c+ spectroscopy, Gaussian-smeared sources should be added and both SS and SP correlators computed.

## Output

Plain-text file `xi_c_plus_2pt_cfg10000.txt` containing one correlator value per time slice (t = 0,…,71) with no header or metadata.
