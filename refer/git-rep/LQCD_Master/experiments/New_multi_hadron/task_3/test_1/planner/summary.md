This revision keeps the original physics target intact while fixing the machine-readable gaps that would have made the execution ambiguous or wrong. The observable is now stated explicitly as a **single local two-baryon correlator** built from one proton block and one single-term Lambda block, with the same combined operator at source and sink. The plan also corrects the quark-count description: the written operator is a local **6-quark** object, not 9-quark.

The main physics correction is in the measurement definition. It now encodes the **combined source and sink operator directly**, lists **both required propagators** (`prop_l_point` and `prop_s_point`), and marks the contraction as a **single-object multi-hadron 2pt** rather than something factorized afterward. This is essential because the Lambda block contains an explicit strange quark and because the requested contraction is not equivalent to multiplying separate proton and Lambda two-point functions.

The spin projection is also made executable rather than advisory text only. The revised plan attaches `P_plus = (1 + gamma_4)/2` **separately to the proton and Lambda baryon blocks** inside the correlator specification, matching the requested per-baryon projection and avoiding the common mistake of projecting only at the composite level.

Reasonable parts of the previous plan are preserved: the ensemble values remain consistent with the supplied configuration block, the point source remains at `[0,0,0,0]` for all quark propagators, stout-smeared links with `(n_steps=1, rho=0.125, ndim=4)` remain attached to the inversions, and the output remains a plain-text file in the run directory.
