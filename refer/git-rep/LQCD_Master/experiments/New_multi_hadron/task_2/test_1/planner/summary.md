This revision keeps the original physics target intact but removes the ambiguities that would have made the execution or contraction logic wrong. The calculation remains a standard hadronic measurement: a zero-momentum `multi_hadron_2pt` built from the local nine-quark operator \(O=[(u^T C\gamma_5 d)d][(u^T C\gamma_5 d)u][(u^T C\gamma_5 d)d]\), using only the single-term neutron-like, proton-like, neutron-like baryon blocks requested by the user.

The main physics correction is that the source and sink are now encoded explicitly as one combined composite operator inside the structured correlator definition, rather than only as three separate baryon entries plus free-text notes. This makes it unambiguous that the backend must generate a single fully contracted nine-quark `multi_hadron_2pt` object, with all Wick contractions belonging to the complete local operator, and not a product of three independently measured baryon two-point functions. To prevent accidental factorization, the correlator specification now states that the object is combined, non-factorized, and must include cross-baryon contractions within the full multi-hadron contraction.

The spin projection requirement is also promoted from an informal note to structured measurement data. Each of the three baryon sub-blocks at both source and sink carries its own `P_plus = (1 + gamma4)/2` projector. This matches the user instruction and is the correct implementation for a blockwise baryon projection, rather than a single projector applied only at the composite nine-quark level.

On the numerical side, the propagator plan remains economical and physically appropriate. Because the operator contains only `u` and `d` quarks and the ensemble has degenerate light flavors, one light-quark propagator from a point source at `[0,0,0,0]` is sufficient and is reused for all nine quark lines by isospin symmetry. The stout smearing parameters requested by the user are retained, but the solver notes now explicitly state the intended interpretation: the clover inversions are performed on the once-stout-smeared gauge links, while the source and sink interpolating operators themselves remain local and unsmeared. That removes an important ambiguity in the measured observable.

Finally, the execution and output specifications are made deterministic. The MPI layout is now consistently set to 8 ranks with process grid `[1,1,2,4]`, matching the requested 2-node × 4-GPU setup, and the output block now specifies a plain-text file path in the run directory so the executor has a concrete target artifact to write.
