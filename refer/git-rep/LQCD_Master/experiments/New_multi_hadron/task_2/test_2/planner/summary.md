## Revised plan summary
The revised plan keeps the original objective and structure, but fixes the four issues that would have made the setup unreliable for production. It now defines a single `multi_hadron_2pt` observable for the local nine-quark neutron-proton-neutron operator, with the combined flavor content corrected to `u^3 d^6` and with explicit source and sink block composition so the contraction is generated as one genuine 9-quark object rather than as a product of separate baryon correlators.

The per-baryon parity projection is now encoded directly in the structured hadron definitions: each neutron and proton block appears separately at source and sink, and each block carries its own `P_plus=(1+gamma4)/2` projection. This removes the ambiguity that could otherwise let a generator apply a single composite projector or omit the source-side projection.

The execution layout is also corrected in the actionable plan fields. The ensemble section now uses the requested 8-rank decomposition with `process_grid = [1,1,2,4]`, matching the intended `grid_size` for a 2-node × 4-GPU run. In addition, the propagator entry binds the requested stout smearing unambiguously to the light-quark Dirac operator used in the inversion, which is the correct interpretation of “stout smeared gauge links for the inversions.”

Numerically, the plan remains conservative and executable: one light point-source propagator from `[0,0,0,0]` is reused for all nine quark lines by isospin symmetry, zero momentum is kept throughout, and the result is written as a plain text correlator file in the run directory with metadata retained. This preserves the sensible parts of the previous plan while making the multi-hadron contraction specification tight enough for downstream code generation.
