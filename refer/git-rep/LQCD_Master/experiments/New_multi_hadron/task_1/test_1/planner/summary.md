- The main correction is that the per-baryon positive-parity projection is now encoded explicitly and machine-readably on both baryon blocks through `spin_projector: P_plus`, and the combined source/sink operators state that block spin projection is applied per baryon before composition.
- The six-quark operator is no longer left as an unstructured free-form object alone. Instead, the source and sink are defined explicitly as local two-baryon operators composed from the named `neutron_block` and `proton_block`, with a `combined_multi_hadron_single_object` contraction strategy to force the full six-quark Wick contraction including exchange terms.
- The momentum semantics are clarified: this is a local operator with zero total momentum, and there is no separate baryon-relative momentum projection. That removes the ambiguity between a local six-quark correlator and a product of independently momentum-projected baryon correlators.

The light propagator is solved on stout-smeared links with the requested parameters `(n_steps=1, rho=0.125, ndim=4)`, and the correlator measurement explicitly records that the same smeared-link definition underlies the observable.
- The executable setup remains minimal and efficient: one light point-source propagator from `[0,0,0,0]`, reused for all `u` and `d` lines through isospin symmetry, one configuration on the `C24P29` ensemble, and plain-text output written to `./dibaryon_local_2pt.txt` in the run directory.
