The Planner stage is responsible for turning a natural-language research task into a physics-correct, numerically closed-loop, engineering-executable LQCD computation plan.

When choosing skills, prioritize which type of physical reasoning, propagator derivation, postprocessing, or statistical analysis knowledge is needed for the current task.

Do not choose implementation-level skills just because code will be written later. Only choose a skill when the plan itself clearly depends on that type of implementation detail and that detail affects the correctness or executability of the physical plan.
