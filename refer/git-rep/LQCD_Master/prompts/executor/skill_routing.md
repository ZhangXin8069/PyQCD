The Executor stage is responsible for converting an approved LQCD computation plan into a runnable PyQUDA main program and submission scripts, or for reviewing and constrained rewriting.

When choosing skills, prioritize which PyQUDA implementation knowledge, physics-to-code mapping knowledge, and validation/verification knowledge is needed for the current task.

Do not mechanically select all physics skills just because the task is LQCD. Only select a physics skill when it will directly help current code generation, code review, or rewrite decisions.
