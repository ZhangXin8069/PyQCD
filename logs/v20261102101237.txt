# 胶子 TMD-PDF 全链依赖关系与作用对象

## 1. 记号与分层

令：

- `U0` 为原始规范链接。
- `U_ext` 为核子外部态 Dirac 求解实际使用的规范链接。若未使用 HYP/stout，则 `U_ext=U0`。
- `V_tau = WilsonFlow(U0; tau, eps)` 为 Wilson-flowed gauge。
- `E` 为 Dirac 特征矢/eigensystem。
- `P` 为 light perambulator。
- `S_mom` 为源/汇 momentum-smear 操作及其参数。
- `O` 为胶子 TMD OPE 算符；`O_nonflow` 使用非-flow 规范链接，`O_flow` 使用 `V_tau`。
- `C2` 为 source-resolved 核子两点函数；`C3_ext` 为 connected 3pt 控制道；`C3_g` 为胶子 OPE 与外部态收缩得到的 disconnected 胶子三点。

需要先固定两个边界：

1. `C3_ext` 是普通的 connected 3pt 控制道，不是胶子 TMD 的 disconnected 三点。
2. `O` 本身是裸的 flowed/non-flowed 胶子算符矩阵元候选；只有与 `C2`/外部 loop 结合后，才进入 `C3_g` 和 ratio 链。

## 3. 四个操作的作用对象

### 3.1 HYP

- 作用对象：用于 Dirac 求解、特征矢和 perambulator 生成的规范链接 `U_ext`。
- 影响：`U_ext -> E -> P -> VVV/VdV、2pt、connected-3pt`。
- 若 HYP 仅用于外部态，而 OPE 使用原始 thin-link，则它是外部态层的 HYP，不是 OPE 的 flowed gauge。
- 若 OPE 也声明使用 HYP 链接，则必须把 `U_OPE=U_HYP` 写入 OPE contract；不能把它标成 Wilson-flow 结果。

### 3.2 stout

- 作用对象：与 HYP 同属规范链接平滑，通常用于 Dirac/特征矢/perambulator 的 `U_ext`。
- 影响：`U_ext -> E -> P -> VVV/VdV、2pt、connected-3pt`。
- stout 参数属于外部态身份；不同 stout 参数不能共用同一 `P`、`E` 或 2pt/3pt。
- stout 不等于 Wilson flow，不能用 stout 迭代次数替代 `tau=t/a^2`。

### 3.3 momentum-smear

- 作用对象：夸克源/汇场，不是规范链接，也不是 flowed gauge。
- 影响：`S_mom + U_ext + E -> P`，进而影响 boosted 核子 2pt/connected-3pt 的外态重叠。
- 复用条件：源/汇类型、动量、smear 参数、边界、Dirac 约定和 perambulator 完全一致。
- momentum-smear 不应进入 OPE 的 `V_tau` contract；它属于外部态层。

### 3.4 Wilson-flow

- 作用对象：进入胶子 TMD OPE 的规范链接；当前 PyQCD 主链为 `V_tau = WilsonFlow(U0; tau, eps)`。
- 影响：`V_tau -> O_flow -> C3_g -> ratio -> c0 -> PDF/TMD-PDF`。
- 当前主链不把 `V_tau` 自动送入 `E`/`P`，所以普通 2pt/connected-3pt 不因 `tau` 自动改变。
- 若采用“先流化整个规范场，再求解 Dirac”的变体，则 `V_tau` 也作用于外部态，必须重算 `E、P、VVV/VdV、2pt、connected-3pt`。这是与当前主链不同的方案。

## 4. 不使用 Wilson flow 的依赖链

```text
U0
  -> [可选 HYP/stout] -> U_ext
  -> U_ext -> E
  -> U_ext + E + [momentum-smear on source/sink] -> P
  -> E -> VVV/VdV
  -> P + VVV/VdV -> C2 / C3_ext

U_OPE = U0 或明确声明的 U_HYP/U_stout
  -> O_nonflow
  -> O_nonflow + C2/外部 loop -> C3_g
  -> C2 + C3_g -> ratio
  -> ratio -> c0
  -> ratio -> Sumratio (质量/平台诊断分支)
  -> c0/hB + [soft/rapidity/multi-scale] -> Z_R/hybrid -> h_R
  -> c0/h_R + Fourier + [matching/soft/rapidity] -> PDF/TMD-PDF
```

作用对象标注：

- HYP/stout：`U0 -> U_ext`，作用于外部态 Dirac/特征矢/perambulator 所用的规范链接。
- momentum-smear：作用于源/汇夸克场，进入 `P` 和 2pt/connected-3pt。
- 非-flow OPE：作用于 `U_OPE=U0` 或明确声明的 `U_HYP/U_stout` 规范链接。
- 这条链中的 `ratio/c0` 是非-flow OPE 的下游，不能直接套到 `V_tau` 的 flow OPE 上。

## 5. 使用 Wilson flow 的依赖链

```text
U0
  -> V_tau = WilsonFlow(U0; tau, eps)
  -> V_tau -> O_flow

U0
  -> [可选 HYP/stout] -> U_ext
  -> U_ext -> E
  -> U_ext + E + [momentum-smear on source/sink] -> P
  -> E -> VVV/VdV
  -> P + VVV/VdV -> C2 / C3_ext

O_flow + C2/外部 loop -> C3_g(tau)
  -> C2 + C3_g(tau) -> ratio(tau)
  -> ratio(tau) -> c0(tau)
  -> ratio(tau) -> Sumratio(tau) (质量/平台诊断分支)
  -> c0(tau)/hB(tau) + [soft/rapidity/multi-scale] -> Z_R/hybrid -> h_R(tau)
  -> c0(tau)/h_R(tau) + Fourier + [matching/soft/rapidity] -> PDF/TMD-PDF(tau)
```

作用对象标注：

- Wilson-flow：`U0 -> V_tau`，只作用于进入胶子 OPE 的规范链接；每个 `tau` 对应独立的 OPE contract。
- HYP/stout：若存在，只通过 `U0 -> U_ext` 进入外部态 `E/P`；不能把 `U_ext` 当作 `V_tau`。
- momentum-smear：只作用于源/汇夸克场，进入 `P` 和 2pt/connected-3pt；不进入 OPE 的 flowed-gauge contract。
- `O_flow` 及其下游 `ratio(tau)、c0(tau)、h_R(tau)、PDF/TMD-PDF(tau)` 必须使用同一 `tau/eps/几何/staple/精度` 身份。

如果采用“全流化外部态”变体，则应改写为：

```text
U0 -> V_tau
V_tau -> E_flow
V_tau + E_flow + momentum-smear -> P_flow
E_flow -> VVV/VdV_flow
P_flow + VVV/VdV_flow -> C2_flow / C3_ext_flow
V_tau -> O_flow
O_flow + C2_flow/外部 loop -> C3_g(tau) -> ratio(tau) -> ...
```

该变体不是当前 PyQCD 主链；采用它时，VVV/VdV、2pt、connected-3pt 不能沿用旧的非-flow 外部态缓存。

## 6. 当前任务的状态边界

当前 6250–8450 目标链的准确定位是：

- 已完成/正在完成：`U0 -> V_tau -> O_flow`、外部态 `E/P -> VVV/VdV、C2、C3_ext`、以及 `O_flow` 与外部态的 ratio/c0 诊断。
- `Sumratio`：作为 ratio 平台稳定性诊断，不替代 `c0`，也不直接进入 PDF。
- `Z_R/hybrid`：接口存在，但单格距、单系综、缺 soft/rapidity 和完整混合输入时只能保留 `not_identifiable`/`diagnostic_only`。
- `PDF/TMD-PDF`：Fourier/准量诊断可以生成；物理 TMD-PDF 仍要求 soft/rapidity、完整混合/匹配和多尺度极限。
- 当前状态必须保持 `diagnostic_only`、`physical_acceptance=false`，不能把 `O_flow`、`ratio` 或 `c0` 直接命名为物理 TMD-PDF。

## 7. 结论

1. HYP/stout 和 momentum-smear 不是“与 2pt/3pt 无关的数据”；它们属于外部态层，可能是 2pt/3pt 的必要输入。
2. Wilson-flow 是胶子 OPE 层的独立规范链接变换，不自动改变当前外部态；它的输出 `V_tau` 必须按 `tau` 重算 OPE。
3. VVV/VdV、2pt、connected-3pt 可在相同外部态合同下复用；OPE 和其下游 ratio/c0/PDF 必须匹配所用规范链接方案。
4. 若切换为“全流化外部态”，则外部态及其所有顶点/关联函数都要重算，不能沿用旧缓存。
