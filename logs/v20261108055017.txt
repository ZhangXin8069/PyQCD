## 关键日志

### S1 — 基准口径改造（主代理）
- 目标: 让基准可复核、且与生产用法一致
- 命令/操作: 改 `pyqcd/testing/einsum/bench_distillation.py`
  - 新增 `--data real|synthetic`（真实数据缺失时用固定种子合成，产物 `provisional=true`）
  - 新增 `--planner production|shared`（production=双方各自按 `--optimize` 规划一次、只计稳态执行；
    shared=双方共用 oracle 显式 path，只隔离执行层）
  - 默认 `--optimize` 由 greedy 改为 `dp`（用户指示 opt_einsum 常用策略）
  - 新增 `MIN_MEANINGFUL_SECONDS = 0.1`：双方中位耗时均 <0.1 s 的行记 `too_short`，
    不计入 3x 判定（用户指出 E4/E5 耗时过短不能作实战对照）
- 关键输出: 冒烟 7 条方程全部跑通；S1/S2/S3 rel ≤ 1.2e-15
- 退出码: 0
- 证据与判断: 曾出现 `max relative error = inf`，根因是 production 模式下把空 path 传给 oracle 侧；
  修正后正常。实现本身无错（直接对拍 S1 rel=0、S2 rel=6.1e-16、S3 rel=4.3e-16）
