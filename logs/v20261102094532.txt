--- report begin ---
结论：不能全部复用，也不能全部重算。梯度流重整化改变的是胶子 TMD 算符使用的规范链接，不是蒸馏顶点或外态关联函数的定义。

| 对象 | 是否重算 | 条件与原因 |
|---|---|---|
| VVV/VdV | 通常不需要 | 只依赖原始组态、特征矢量/perambulator、动量、Nev、精度和收缩约定，不依赖 flow tau。相同身份下可复用。 |
| HYP/stout/momentum smear | 不能当作梯度流直接复用 | 它们是不同的 UV 平滑/方案；旧 HYP/stout/momentum-smear 数据不能冒充 Wilson-flow 数据。 |
| 2pt | 通常不需要 | 2pt 是核子/π 外态关联函数，不包含 flowed 胶子流算符。只要组态、插值算符、perambulator、动量、边界和极化定义一致即可复用。 |
| connected 3pt | 通常不需要 | 与 2pt 同理；它用于外态和激发态控制，不因胶子流算符采用 flow 方案而改变。 |
| OPE/胶子 TMD 矩阵元 | 必须重算 | OPE 直接消费 flowed gauge V_tau，并依赖 tau、eps、z、b、staple、方向和算符组合。非 flow OPE 不能直接用于 flow 方案。 |
| ratio、c0、Sumratio、Z_R/hybrid、PDF/TMD-PDF | 必须基于新 OPE 重算 | 这些量消费 flowed OPE，不能从非 flow OPE 的旧 ratio 直接套用。 |

代码依据：`compute_vertices_multi`、`compute_2pt_polarizations_multi`、`compute_2pt_for_config` 和 `compute_3pt_for_config` 都没有 flow tau 参数；`compute_tmd_ope_time` 与 `compute_tmd_ope_time_2d` 显式调用 `flow_gauge_for_config`，且 OPE contract 包含 `flow_contract_sha256`。当前 flowed 胶子 OPE metadata 明确记录 `input_scheme=thin_link_no_hyp_no_smear`。

需要区分“smear”的两种含义：Wilson flow 本身必须对每个 tau 从同一原始 gauge 独立重算；源汇插值算符的 smearing 属于外态定义，只有完全相同才可复用。旧 HYP/stout/momentum smear 不能替代 Wilson flow。

实际迁移顺序：先审计 conf ID、原始 gauge hash、特征矢/perambulator、动量、精度、源汇插值、边界和算符约定；通过后复用 VVV/VdV 与相同定义的 2pt/connected 3pt；为 tau=1,2,3 重新生成 flowed gauge；重新计算 full-channel、legacy 与 2D staircase OPE；最后重跑 ratio、c0/Sumratio、Z_R/hybrid、准 PDF 与诊断 TMD-PDF。只有旧 OPE 已经采用相同 flow tau/eps/几何/算符约定时才可直接复用；单个 tau=3 也不足以完成流时重整化。
